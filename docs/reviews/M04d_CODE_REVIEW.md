## 2. Analyse Approfondie des Fichiers Modifiés

### 2.1 `crates/core/src/local_llm.rs`
- **Découplage GGUF & Serveur Personnalisé** :
  - `is_inference_ready()` vérifie `is_model_loaded()` OU présence d'un `daemon_endpoint` valide.
  - `generate_stream()` autorise le streaming sans modèle local dès lors qu'un daemon est configuré.
  - `fetch_remote_models()` interroge `{endpoint}/models` avec timeout défensif (connect 1.5s, total 3s) et support du Bearer auth via `daemon_api_key`.
- **Ciblage par défaut Qwen3.5-2B** :
  - Repli `default_path` sur `Qwen3.5-2B-Q4_K_M.gguf` (~1.28 Go).
  - `fetch_models()` retourne `["Qwen3.5-2B-Q4_K_M.gguf"]` en fallback.
  - `detect_daemon_model_name()` utilise `"qwen3.5:2b"` comme repli d'inférence distante.
- **Sécurité Mémoire & Robustesse** :
  - Zéro `unwrap()` dans les chemins chauds et de production.
  - Gestion des timeouts et propagation des erreurs vers `LlmError`.

### 2.2 `crates/core/src/model_discovery.rs`
- **Algorithme de Résolution Tolérant** :
  - Priorité absolue aux modèles Qwen 2B / 3.5 (`file_name.contains("qwen") && (file_name.contains("2b") || file_name.contains("3.5"))`).
  - Maintien d'un repli secondaire automatique sur Qwen 3B (`qwen2.5-3b-instruct-q4_k_m.gguf`) pour garantir la rétrocompatibilité.
  - Tri dans `discover_models_in_dirs()` ordonnant le modèle actif, puis Qwen 2B / 3.5, puis Qwen 3B, puis ordre alphabétique.
