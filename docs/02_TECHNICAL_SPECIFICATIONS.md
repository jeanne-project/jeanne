# 02 - Technical Specifications

## 1. Data Models & SQLite Schema

### 1.1 Standard Markdown Frontmatter
All notes managed or generated by Jeanne must include the following YAML metadata:
```yaml
---
id: "note_20260912_103000"
title: "Technical Architecture Review"
date_creation: "2026-09-12T10:30:00Z"
date_modification: "2026-09-12T10:30:00Z"
type: "semantique" # semantique | episodique | procedural
statut: "actif"     # actif | obsolete | archive
tags:
  - "architecture"
  - "review"
source_media: "Attachments/meeting_20260912.wav" # Optional
---
```

### 1.2 Derived SQLite Index Schema (`database.db`)
```sql
CREATE TABLE files (
    file_path TEXT PRIMARY KEY,
    file_hash TEXT NOT NULL,
    last_modified INTEGER NOT NULL,
    frontmatter_json TEXT
);

CREATE TABLE chunks (
    chunk_id TEXT PRIMARY KEY,
    file_path TEXT NOT NULL,
    chunk_index INTEGER NOT NULL,
    content TEXT NOT NULL,
    token_count INTEGER NOT NULL,
    note_type TEXT NOT NULL,
    statut TEXT NOT NULL,
    date_creation INTEGER NOT NULL,
    FOREIGN KEY(file_path) REFERENCES files(file_path) ON DELETE CASCADE
);

CREATE VIRTUAL TABLE vec_chunks USING vec0(
    chunk_id TEXT PRIMARY KEY,
    embedding FLOAT[384] -- Local dense model (bge-small / e5-small)
);

CREATE VIRTUAL TABLE fts_notes USING fts5(
    chunk_id UNINDEXED,
    content,
    file_path UNINDEXED,
    tokenize = 'porter unicode61'
);
```

## 2. Hybrid RAG Algorithm & Time-Decay Ranking

### 2.1 Time-Decay Relevance Formula
To eliminate context rot and prioritize recent records while respecting verified semantic ground truth:

$$\text{Final\_Score} = \left( w_v \cdot S_{\text{vector}} + w_l \cdot S_{\text{BM25}} \right) \times \frac{1}{1 + \lambda \times \Delta t_{\text{days}}}$$

* $w_v = 0.7$ (Cosine vector similarity weight).
* $w_l = 0.3$ (Normalized FTS5 BM25 lexical weight).
* $\Delta t_{\text{days}} = (\text{Current\_Timestamp} - \text{Creation\_Timestamp}) \text{ in days}$.
* $\lambda = 0.005$ (Configurable decay rate; $\lambda = 0.0$ for procedural or immutable knowledge).
* **Exclusion Filter**: Records with `statut IN ('obsolete', 'archive')` are omitted by default unless historical queries are requested.

### 2.2 Confidence Scoring & Strict Anti-Hallucination
* If $\max(S_{\text{vector}}) < 0.65$: The LLM generation is bypassed entirely. The UI outputs:
  > *"Information not found in your documents."*
* Every factual claim generated by the LLM must append its explicit source citation: `[source: filename.md]`.

## 3. Meeting Module: Zero-Compute Stereo Diarization
* **Audio Capture**: 16 kHz 16-bit PCM recording in **stereo (2 channels)**:
  * **Channel 0 (Left)**: Local user microphone.
  * **Channel 1 (Right)**: WASAPI System Loopback (remote speakers via Teams, Meet, Zoom).
* **Deterministic Diarization**: RMS energy comparison between the two channels during Whisper transcription. Labels speakers (`[Me]` vs. `[Remote]`) with zero neural diarization overhead.
* **Interactive Time-Seeking**: Markdown timestamps (`[[00:14:30]](seek:870)`) are interactive links that trigger the embedded Tauri player to seek to the exact second in the original media.

## 4. Hybrid Inference & Local PII Masking
* **Local Provider**: Embedded `llama.cpp` with Vulkan backend.
* **Remote Provider**: HTTP client targeting any OpenAI-compatible API endpoint (`/v1`).
* **Local PII Filter**: When operating in remote mode, a deterministic local regex scanner substitutes emails, phone numbers, and financial figures (`[EMAIL_1]`, `[PHONE_1]`) prior to network transmission, and reverses substitutions upon receiving SSE stream chunks.
